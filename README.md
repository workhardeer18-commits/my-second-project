# پروژه تیکت (Ticket-CBV)

یک سیستم مدیریت تیکت توسعه‌داده‌شده با Django و استفاده از Class-Based Views (CBV).

## قابلیت‌ها
- ایجاد، مشاهده و مدیریت تیکت‌ها توسط کاربران.
- استفاده از کلاس‌های ویو برای ساختاردهی بهتر کدها.

## نحوه اجرا
1. کلون کردن پروژه:
   `git clone https://github.com/workhardeer18-commits/my-second-project.git`
2. نصب پیش‌نیازها:
   `pip install -r requirements.txt`
3. اجرا:
   `python manage.py runserver`
